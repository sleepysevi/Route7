# Route7

Route7 is a React-based web application designed to help users navigate local jeepney routes, discover popular hiking spots, and access a local dialect dictionary in Cebu.

## Features

* **Route Navigation (`RoutesTab`):** Search and select specific jeepney routes for easier commuting.
* **Hiking & Tourist Spots (`SpotsTab`):** Browse a curated list of local outdoor spots complete with latitude and longitude coordinates.
* **Local Dictionary (`DictTab`):** Look up local terms and phrases.
* **Modern UI:** Built with a responsive, dark-themed interface featuring a glassmorphic navbar, custom toast notifications, and an introductory splash screen.
